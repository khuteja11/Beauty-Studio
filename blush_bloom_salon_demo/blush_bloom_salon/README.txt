BLUSH & BLOOM BEAUTY STUDIO — DEMO WEBSITE

FILES
- index.html: page structure and content
- style.css: colours, layout, responsive design
- script.js: mobile menu, current year, service selection, WhatsApp enquiry form

HOW TO RUN
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Internet is needed for Google Fonts and the remote demo photos.

BEFORE SHOWING A REAL CLIENT
1. Replace the fictional salon name, copy, services, address, hours, and photos with client-approved details.
2. In script.js, replace SALON_WHATSAPP_NUMBER with the owner's real number, digits only, including country code.
3. Test the form with a real number only after the owner gives permission.
4. Make sure you have permission to use every photo, logo, and other asset.
5. The form opens WhatsApp; it does not save bookings or send them automatically.

FREE PUBLISHING
You can publish this static site with GitHub Pages. Create a GitHub repository, upload these three files to the repository root, then open Settings > Pages and choose the main branch and root folder as the source. Wait for GitHub Pages to provide the live URL. A custom domain is optional and usually costs money.

NOTE
This is a fictional portfolio demo. Images are loaded from Unsplash remote URLs and require internet access. Replace them with properly licensed or client-owned photos for a real project.
